各阶段对内存布局的影响对比表\

|阶段	|确定的内容	|是否影响内存？	|示例|
|预编译阶段	|宏展开、头文件包含、条件编译、#pragma 指令	|✅ 间接影响	#define SIZE 100 → 影响数组大小 int arr[SIZE];|\
                                                                |#include <stdio.h> → 可能引入全局变量或函数|\

|编译阶段	|生成 .text（代码）、.data（初始化数据）、.bss（未初始化数据）、.rodata（常量）	|✅ 确定逻辑布局	int x = 5; → 进入 .data，const int y = 10; → 进入 .rodata|\
                                                |计算栈帧布局（局部变量偏移量）	  |✅ 布局确定，地址未定	void foo() { int a; } → 编译器计算 a 在栈帧中的偏移|\

|链接阶段	|合并多个 .o 文件，解析符号地址，生成可执行文件（如 PE/ELF）	|✅ 确定虚拟地址	main() 的地址被固定，全局变量 int g_var; 的地址确定|\
|运行时	|操作系统加载可执行文件，分配物理内存（.text、.data、.bss、栈、堆）	|✅ 实际内存分配	malloc(100) → 堆内存分配，int local; → 栈内存分配|\

关键内存段在各阶段的状态\
|内存段	|预编译阶段|	编译阶段|	链接阶段|	运行时 | \
|.text	|❌ 未生成	|✅ 生成机器码	|✅ 分配虚拟地址	|✅ 加载到物理内存|\
|.data	|❌ 未生成	|✅ 记录初始值	|✅ 分配虚拟地址	|✅ 加载并初始化|\
|.bss	|❌ 未生成	|✅ 记录大小（未初始化）	|✅ 分配虚拟地址	|✅ 由 OS 初始化为 0|\
|.rodata	|❌ 未生成	|✅ 记录常量	|✅ 分配虚拟地址	|✅ 加载为只读内存|\
|Stack	|❌ 无关	|✅ 计算布局（偏移量）	|❌ 无关	|✅ 运行时动态分配|\
|Heap	|❌ 无关	|❌ 仅生成 malloc 调用	|❌ 无关	|✅ 运行时动态分配|
